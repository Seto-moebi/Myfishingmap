このフォルダに、各魚種のボタン背景に使う写真を置いています。
ファイル名は config.js の image に合わせます。

  magochi.jpeg   … マゴチ
  koshodai.jpeg  … コショウダイ
  kijihata.jpeg  … キジハタ
  mebaru.jpeg    … メバル
  mejina.jpeg    … メジナ
  aji.jpeg       … アジ
  kurodai.jpeg   … クロダイ
  suzuki.jpeg    … スズキ
  tachiuo.jpeg   … タチウオ

・縦長〜正方形の写真が見栄えします（ボタンは縦3:横4の比率で中央トリミング表示）。
・写真を差し替えるときは同じファイル名で上書きしてください。
・ファイル名や拡張子を変えた場合は config.js の image を書き換えてください。
