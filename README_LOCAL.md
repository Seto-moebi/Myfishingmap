# 各端末で使うローカル版（`index.html` / `local_map.html`）

いったんサーバー共有（Cloudinary）をやめて、各端末ごとに独立してマップを育てる方式に戻しました。
さらに、行った場所（目的）ごとにマップを分けられるようにしています。

## 使い方
1. `index.html`・`local_map.html`・`config.js` をまとめて各端末（スマホ・PC）に配布する（フォルダごとLINE・AirDrop・メールなどで送るか、3つ同じフォルダに置く）
2. `index.html` を開くとLP（場所を選ぶ一覧）が出るので、行った場所をタップ
3. その場所専用の地図（`local_map.html?map=...`）が開くので、写真をドラッグ＆ドロップ、またはタップして選択すると、GPS付きの写真は自動でピンが立つ
4. 地図の左上「← マップ一覧」からLPに戻れる

写真・ピン・題名は、**選んだ場所ごとに分けて**その端末・そのブラウザの中（IndexedDB）にだけ保存されます。他の端末やサーバーには送信されません。
- ブラウザのキャッシュ／サイトデータを消すと、保存した写真も消えます
- 同じ端末でも、別のブラウザ（Safari→Chromeなど）で開くと別のデータになります
- インターネット接続は必要です（地図タイル・地図ライブラリをCDNから読み込むため）

## 場所（マップ）の追加・変更
`config.js` の `FISHING_MAPS` 配列を編集するだけです。`id` はURLの `?map=` に使われる半角英数字、`label`/`desc` は画面に表示される文言です。ここに項目を足せば、LPにもカードが自動で増えます。

## 各端末のマップが育ってきたら
`server.py` / `templates/map.html`（Cloudinary連携版）はそのまま残してあります。共有マップに戻したくなったら、そちらをRenderにデプロイすれば、以前と同じように全端末で同じ地図・同じピンを見られる状態に切り替えられます。手順は `README_DEPLOY.md` を参照してください。
